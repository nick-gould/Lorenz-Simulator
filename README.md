Simulator for the [Lorenz equations](https://en.wikipedia.org/wiki/Lorenz_system) with sliders for starting values of x, y, and z, as well as tunable parameters.

https://nick-gould.github.io/Lorenz-Simulator/

This is a toy project to get python code to run on a static webpage through github pages. This is done by using javascript and pyodide, while plotting using plotly.
